# DiskSentinel

磁盘哨兵
Disk + Sentinel（磁盘 + 哨兵）

设计这个小工具,主要为了我的双4T冷备份硬盘.

可以定期记录硬盘的状态,最后生成数据图表.方便查看硬盘历史状态判断现在硬盘健康度.

还有内部文件的同步状态和检测文件是否损坏.

## 运行

双击 `run.bat`。

- 首次运行会自动创建项目虚拟环境 `.venv` 并安装依赖（需要联网一次，之后不再需要）。
- 平时启动用 `pythonw`，不会留黑色控制台窗口；程序异常会写入
  `data\logs\error.log` 并弹窗提示。
- 需要 Windows 系统；smartctl.exe 已内置在 `tools/` 下，无需安装 smartmontools，
  也不需要配置任何环境变量。
- 普通权限即可读取 SMART 属性；`run_as_admin.bat` 以管理员启动可额外读取
  错误日志、自检日志以及容量等识别信息。

## 数据

全部保存在项目目录 `data/` 下：

```
data/
├─ disks.json                        # 硬盘档案索引
├─ snapshots/<硬盘序列号>/
│  ├─ attributes.csv                 # 指标时间序列，Excel 可直接打开
│  └─ raw/<快照ID>.json              # 每次检测的完整原始 JSON
└─ fileindex/
   └─ index.db                       # 冷备对 SQLite 数据库（Python 自带, 无需安装）
```

两套数据两种形态，各干各擅长的事：
SMART 数据量小、要人眼可读，用文件（CSV/JSON）；冷备对数据量大（百万级）、
要查询，用 SQLite。`index.db` 是单个普通文件，用任何 SQLite 工具
（如免费的 DB Browser for SQLite）就能直接查看，程序本身零依赖。

## 备份与恢复

所有数据都在项目目录 `data/` 下，**备份 = 复制文件夹，恢复 = 复制回来**。
没有任何隐藏数据在别处（注册表、用户目录、系统目录都没有）。

**备份什么：**

| 数据 | 位置 |
|---|---|
| 冷备对 / 自检数据库 | `data\fileindex\index.db`（单文件，含盘对、单盘自检基线与全部校验记录） |
| SMART 快照 | `data\disks.json` + `data\snapshots\` |

最省事：**整个 `data\` 文件夹复制一份**到备份盘或网盘。
`index.db` 旁边平时有 `-wal` / `-shm` 两个伴随文件（SQLite 的预写日志），
程序正常退出会自动合并进主文件；保险起见**关闭程序后再备份**，
拷 `index.db` 一个文件即可。

**恢复：** 关闭程序 → 把备份的 `data\`（或其中对应文件）覆盖回项目目录
同名位置 → 重新打开，历史记录全部还原。

**换电脑 / 挪目录：** 整个项目文件夹（含 `data\`）拷过去，删掉 `.venv`
让 `run.bat` 自动重建。SMART 历史按硬盘序列号关联（换电脑不丢）；
冷备对按路径关联，盘符变了就把对应盘对删掉重新配一次。

**清理重来：** 删除 `data\fileindex\` 整个文件夹 = 冷备对数据全部清空
（下次打开自动重建空库，盘对需重新创建）；`snapshots\` 里的文件请勿手工改名。

## 文件功能（比对 / 校验）

文件功能页有三个子页签：

### 盘对校验

把互为备份的两块硬盘（或任意子目录）配成一对。

- **结构比对**：只读文件名、大小、修改时间，不读内容、不改文件，
  几十 GB 的目录几秒~几分钟。能发现缺文件 / 多文件 / 大小不同 / 时间不同。
- **内容校验**：逐文件读取内容算 SHA-256 再比对，是发现静默损坏
  （如照片下半部分变纯色）的唯一手段。4TB 全量约 6~8 小时/侧，建议挂夜；
  支持暂停续跑。默认**全量重读**——因为静默损坏不改变大小和修改时间，
  沿用旧结果就等于没检查；确认框里可勾选"快速模式"跳过未变动文件
  （快，但发现不了静默损坏）。

### 单盘自检

只有一块盘在手时用：第一次复检建立「基线」，之后每次复检都与基线比。

- **内容损坏**（红）：大小和修改时间都没变、但内容与基线不同——
  这是磁盘位翻转的典型特征，应当用备份覆盖该文件。
- 基线建立后**固定不变**，问题每次都会被报出来，不会被滚动更新吞掉；
  确认当前状态没问题后可用【重建基线】重置。
- 新增 / 已修改属正常使用痕迹；丢失、无法读取需要关注。

### 校验历史

全部结构比对、内容校验、单盘复检的运行记录，选中即看那一次的差异明细。
明细不重复存储，现场从清单重放，不占额外空间。
